LOLIE MARTINEZ — PORTFOLIO V2

1. Ouvrir index.html dans un navigateur.
2. Navigation : accueil, projets, pages projets, photographie, à propos.
3. Pour modifier les textes des projets, éditer data.js.
4. Pour changer la palette, éditer les variables :root dans style.css.
5. Avant publication : remplacer TON-EMAIL@EXEMPLE.FR dans index.html ; ajouter les vraies photos et réalisations ; vérifier chaque description de projet.
6. Les visuels typographiques sont des placeholders volontaires. Aucun résultat chiffré ou photo n’a été inventé.
7. Le site fonctionne en local, sans installation. La police Google nécessite une connexion Internet.
